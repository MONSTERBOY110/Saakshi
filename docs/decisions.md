## Verified payload shapes (2026-09-05, docs plus live capture in `tests/fixtures/`)

- STT token: `GET https://streaming.assemblyai.com/v3/token?expires_in_seconds=60&max_session_duration_seconds=3600` -> `{ token, expires_in_seconds }`.
- Agent token: `GET https://agents.assemblyai.com/v1/token?expires_in_seconds=60&max_session_duration_seconds=3600` -> `{ token }`, single use.
- STT close codes: 1008 unauthorized, 1011 internal, 3005 cancelled, 3006 invalid message/JSON/inactivity, 3007 chunk size or faster than real time, 3008 expired, 3009 too many sessions. 1000/1006 close without an Error frame; 1009 means a frame over 128 KB.
- Agent `session.error.code`: UNAUTHORIZED, FORBIDDEN, INTERNAL_ERROR, server_error, session_not_found, session_forbidden, session_expired, agent_init_failed, agent_timeout, invalid_format, invalid_audio, invalid_value, immutable_field, invalid_config.
- `session.updated` arrives a few ms before `session.ready`; `session.ready` carries `session_id`, `expires_at`, `resume_token` and the full effective config (including `input.language_codes`, `tools`, `llm`, `pre_connect_requests`).
- Greeting audio starts about 160 ms after `session.ready`; `transcript.agent.delta` is per word with `start_ms`/`end_ms`.
- STT `Heartbeat` every 5 s. `SpeakerRevision` arrives about 350 ms before `Termination`, after `Terminate`, and lists only revised turns with full word arrays.
- `SpeechStarted` is emitted by STT before a turn starts (`{ timestamp, confidence }`).
- The agent's own STT (`transcript.user`) segments finer than Ears and missed Hinglish ("Saakshi. clarify." for "Saakshi, verify."); Ears with keyterms got it right. The NUDGE trigger reads the Ears transcript.
